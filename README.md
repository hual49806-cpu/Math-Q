# 萌寵數學餵養樂園 V12

## 新增功能
- 7日每日登入獎勵，斷簽後重新從第1天開始。
- 每答對20題獲得1把鑰匙，3把鑰匙可開神秘寶箱。
- 寶箱可抽金幣、五種隨機飼料與超級獎勵。
- 萌寵待機、互動、飽足、飢餓與拒食動畫。
- 最愛食物增加原飽食度再加10點。
- 拒絕食物會扣除1份飼料，但飽食度不增加：
  - 狗狗拒絕嫩葉套餐
  - 貓咪拒絕營養蛋
  - 兔子拒絕小魚乾
  - 小蛇拒絕骨頭餅乾
  - 小恐龍拒絕胡蘿蔔
- 完整保留並自動升級 V11 永久存檔。
